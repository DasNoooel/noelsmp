NOELSMP RÄNGE

Hier findest du eine Übersicht über alle Ränge auf dem NoelSMP.

MEDIA

MEDIA - Der Rang für Content Creator auf dem NoelSMP

Den MEDIA-Rang wird durch eine Bewerbung im Discord Server erworben! (Anforderungen werden dort erklärt)

MEDIA VORTEILE:

MEDIA Prefix

Gleiche Vorteile wie der BOOSTER-Rang

Mehr Commands als BOOSTER:

/stonecutter
/loom
/anvil

Mehr Vorteile:
Eigener MEDIA Discord-Chat!

BOOSTER

BOOSTER - Discord Booster

Der Rang wird erworben, wenn man auf dem NoelSMP
oder auf dem DasNoooel Discord boostet

BOOSTER VORTEILE:

BOOSTER Prefix

Erweiterte Command-Nutzung:

/ec
/craft
/trash
/tpauto

Mehr Vorteile:
Eigener BOOSTER Discord Chat!
